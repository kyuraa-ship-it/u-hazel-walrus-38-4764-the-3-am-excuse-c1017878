An entry for the [make.fun](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878) bounty "The 3 AM Excuse".

A hardware wallet refuses to sign a transaction at 3 AM — in the voice of a night watchman whose first rule is: no signatures while the moon is the only witness.

Run with Node 22: `node main.ts` writes the one-line entry to `/output/entry.txt`.
